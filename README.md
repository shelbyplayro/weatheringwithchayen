# ฝนจะตกไหมชาเย็น

หน้าเว็บหน้าเดียวสำหรับดูว่าพิกัดหนึ่งจะมีฝนในอีก 0–4 ชั่วโมงหรือไม่ ค่าเริ่มต้นคือพิกัดสวนที่ อ.คีรีรัฐนิคม จ.สุราษฎร์ธานี (9.032760, 98.944311)

## ข้อมูลที่ใช้

| แหล่ง | ใช้ทำอะไร |
|---|---|
| RainViewer (ภาพเรดาร์ย้อนหลัง 2 ชม. ทุก 10 นาที) | หาตำแหน่ง ความเร็ว และทิศของกลุ่มฝน แล้วเลื่อนไปข้างหน้า (0–2 ชม.) |
| Open-Meteo Ensemble API (ECMWF, GFS, ICON) | สัดส่วนสมาชิก ensemble ที่ให้ฝน ≥0.1 มม./ชม. |
| Open-Meteo Forecast API (ECMWF, GFS, ICON, JMA, GEM, CMA) | ปริมาณฝนรายชั่วโมงและ precipitation probability, ลมระดับ 700 hPa ใช้แทนความเร็วกลุ่มฝนเมื่อเรดาร์เห็นฝนน้อยเกิน |
| OpenStreetMap | แผนที่พื้นหลังของภาพเรดาร์ |

ไม่ต้องใช้ API key ทุกอย่างดึงในเบราว์เซอร์ของผู้เปิดหน้าเว็บ และรีเฟรชเองทุก 10 นาที

## วิธีรวมตัวเลข

ความน่าจะเป็นต่อช่วง 15 นาที = w·(เรดาร์) + (1−w)·(แบบจำลอง) โดย w = (1 − t/120)^1.2 เมื่อ t คือนาทีข้างหน้า น้ำหนักเรดาร์จึงเป็น 1 ที่ตอนนี้ ราว 0.44 ที่ 60 นาที และ 0 ตั้งแต่ 120 นาทีขึ้นไป

ฝนพาความร้อนที่ก่อตัวใหม่เรดาร์จะยังไม่เห็น ตัวเลขช่วงบ่ายจึงพึ่งแบบจำลองเป็นหลัก

## บันทึกความแม่นยำอัตโนมัติ

`.github/workflows/chayen-log.yml` รันทุก 20 นาทีบน GitHub Actions เรียก `tools/log.mjs` ซึ่งใช้สูตรเดียวกับหน้าเว็บ (อ่านจาก `index.html` โดยตรง) แล้วเขียนผลลง branch `data`:

| ไฟล์ | เนื้อหา |
|---|---|
| `forecasts.csv` | พยากรณ์ 16 ช่วง × 15 นาทีของแต่ละรอบ แยกค่ารวม ค่าเรดาร์ และค่าแบบจำลอง |
| `observed.csv` | ภาพเรดาร์ทุก 10 นาที: มีฝนบนจุดสวนหรือไม่ และสัดส่วนฝนในรัศมี 1 กม. และ 5 กม. |
| `verify.json` | Brier score, skill เทียบค่าเฉลี่ย, แยกตามระยะเวลาล่วงหน้า และตาราง reliability |

ค่าจริงที่ใช้ตัดสินคือเรดาร์ตรงสวน: ช่วง 15 นาทีนับว่า "ฝนตก" ถ้ามีภาพเรดาร์อย่างน้อยหนึ่งภาพในช่วงนั้นเห็นฝน
